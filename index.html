Megapack Quality Pipeline

Data Pipeline · Streaming · Quality Analytics

Multi-source data pipeline simulating battery module assembly for a manufacturing environment. Cell production streams via Kafka, where each cell is graded using a weighted quality score (capacity, internal resistance, OCV, K-value). An assembly process matches cells to thermal assemblies, computes module efficiency, and applies time-based degradation — modeling real production constraints. Visualized through a Streamlit dashboard.

Kafka (KRaft) → Cell Consumer (quality scoring) → PostgreSQL → Assembly Process → Airflow DAG → Streamlit Dashboard
